## Deskripsi
Program berbasis konsol (Python) untuk membantu guru matematika dalam membaca data nilai siswa dari berkas teks, memvalidasi rentang nilai (0-100), menghitung statistik kelas (rata-rata, minimum, maksimum), menentukan status ketuntasan berdasarkan KKM, dan mengekspor laporan secara otomatis[cite: 34, 38].

## Fitur
- Membaca data nilai dari berkas eksternal (`data/contoh_data.txt`)[cite: 34, 38].
- Memvalidasi rentang input nilai (0 s.d. 100)[cite: 32, 34, 38].
- Menghitung statistik nilai rata-rata, minimum, dan maksimum[cite: 34, 38].
- Menentukan status kelulusan siswa berdasarkan KKM (75)[cite: 34, 38].
- Menyimpan laporan hasil analisis ke dalam berkas teks (`output/laporan.txt`)[cite: 34, 38].
